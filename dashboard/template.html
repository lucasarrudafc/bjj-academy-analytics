BJJ Academy Analytics

Students, attendance and revenue of the Jiu-Jitsu academy I run, taken from raw app data to business decisions with SQL, DuckDB and Python.

View the code on GitHub How it was built

Real data, anonymized. Names, photos, facial-recognition data and contacts were removed; ages and ranks are generalized; every amount is multiplied by an undisclosed factor, so growth rates and proportions are real and absolute values are not.
