How it was built

The same cycle I run at work, applied to a business I own.

1 · Extract & anonymize

Data exported from the academy's management app with names, photos, facial data and contacts removed; ages and ranks generalized; money values scaled.

2 · Stage & validate

01_staging.sql types every column, checks keys between facts and dimensions, and flags owner equity flows.

3 · Model

02_model.sql builds a star schema with a month calendar and a student-month snapshot for growth and churn.

4 · Measure & publish

03_kpis.sql defines every KPI; a Python script runs it in DuckDB and renders this static page.
